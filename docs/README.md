# Design notes and experiment protocols

Each protocol was written and frozen before its experiment ran, so the results could not change the rules afterward. Outcomes, including failed experiments, are recorded in the files themselves.

| File | What it covers |
|---|---|
| `experiment-protocol.md` | Shared definitions, evaluation weeks and constants used by every experiment |
| `model-plan.md`, `next-implementations.md`, `stage2-design.md` – `stage4-design.md` | Design of the game-winner model, built in stages |
| `game-model-improvement-plan.md` | Testing whether extra inputs beat the closing line |
| `lstm-fix-protocol.md` | Tuning variants for the LSTM player model |
| `model-alternatives-protocol.md` | Alternative model architectures compared against the LSTM |
| `edge-experiments-protocol.md` | New information sources and bet filters for paper trading |
