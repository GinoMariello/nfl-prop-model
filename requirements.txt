# nfl_data_py 0.3.3's own metadata declares `pandas<2.0,numpy<2.0` -- stale,
# and incompatible with pandas>=2.2 above (which the rest of this codebase
# requires and already runs on). A plain `pip install -r requirements.txt`
# will therefore either fail to build pandas from an old sdist, or downgrade
# pandas/numpy under this package. Verified empirically instead: installed

# pandas==3.0.5/numpy==2.5.3, then called the two functions this project
# actually uses -- both returned correct data:

#   pip install --no-deps nfl_data_py
